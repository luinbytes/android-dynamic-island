# Hold Assist and the call indicator

[Specification index](../../REFERENCE_SPEC.md) · [R10t capture](../reference/02b-system-activities-capture.md) · [Live Voicemail](51-live-voicemail.md)

Apple's iOS 27 Phone guide says a person can tap the **green call indicator** to return to an ongoing call from another app. During a held call, Hold Assist can wait for a live agent, notify the person when one is available, transcribe the missed part and offer **Answer Call** to rejoin. The guide shows Hold Assist on the call screen; it does **not** say the waiting or agent-return phases become distinct Dynamic Island content. R10t tests the actual target-phone indicator, alert and return path without inventing a Hold Assist card. Availability varies by country or region. [iOS 27 Phone guide](https://support.apple.com/guide/iphone/while-on-a-call-iph3c9951d7/27/ios/27), [iOS 27 FaceTime audio tools](https://support.apple.com/guide/iphone/use-facetime-audio-call-tools-iph32615672c/27/ios/27).

## R10t native capture

Use a consenting test call with a repeatable hold/agent-return cue. Record carrier/region, Phone settings, automatic Hold Assist Detection setting, Focus/Silent state and whether Phone or FaceTime audio owns the call. Start with the call visible, enter hold, enable Hold Assist manually; repeat with automatic detection enabled and disabled. Move to Home and another app, then inspect the green indicator while waiting, when an agent is detected, after tapping the notification/indicator to return, after **Answer Call**, and after ending. Repeat locked and with a second Live Activity visible. Record Island versus status-bar placement **or absence**, body/content/alert geometry and timing, tap destination, distinct call and assistance IDs if observable, transcription location and privacy, notification sound/wake, actual rejoin result, and teardown. Separate the system notification from an Island expansion in the evidence.

## Android route

Google Phone's **Hold for Me** is a device, country, language and dialer dependent native call feature. Its documented path starts from an eligible call, waits on hold, shows a Phone-app card, prompts when a representative returns and provides **Return to call**. It is not a public cross-app notification schema or authority for a standalone Island overlay to detect an agent, transcribe audio or resume another dialer's call. On the selected Android phone, inspect the installed default dialer, actual feature availability, delivered notification/actions if any, ongoing call chip, keyguard and return result. A target-specific SystemUI renderer may coordinate the call indicator only after tracing the dialer/Telecom owner and must leave the genuine native rejoin flow usable. [Google Phone Hold for Me](https://support.google.com/phoneapp/answer/10071878?hl=en-GB), [Android InCallService](https://developer.android.com/reference/android/telecom/InCallService).

R10t is `unverified` for current iPhone Island styling and all paired layers. If the selected Android dialer does not publish Hold for Me state/actions to the integration route, record the functional gap instead of drawing an apparent agent-ready state.
