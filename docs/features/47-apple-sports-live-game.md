# Apple Sports live-game activity

[Specification index](../../REFERENCE_SPEC.md) · [R10o capture](../reference/02b-system-activities-capture.md) · [Android admission](../android/20-notification-admission.md)

Apple's current Sports guide says a game can have a Live Activity **scheduled before it starts**, manually followed from its game card, or enabled automatically for favorite teams. It describes live scores and plays on the Lock Screen and Apple Watch, and lets the user turn off a game's alerts from the Lock Screen or game card. The iOS 27 News guide says Follow Live hands a game to Apple Sports and describes updates on the Home Screen and Lock Screen. An older iOS 16 release note explicitly placed **Apple TV** live scores in the Dynamic Island, but these current guides do **not** explicitly confirm Apple Sports' iPhone 18 Pro Max/iOS 27 Island presentation. Treat R10o as a positive-or-negative native measurement candidate, not a confirmed current Island card. [Apple Sports game guide](https://support.apple.com/en-sg/guide/apple-sports-app/apdc0cb7ad64/web), [iOS 27 My Sports guide](https://support.apple.com/guide/iphone/follow-your-favorite-teams-with-my-sports-iph1a30f25eb/27/ios/27), [older Apple TV Island note](https://support.apple.com/en-us/101566).

## R10o native capture

In an available region with a real scheduled game, log the Apple Sports/News/TV app versions, game ID, league, team-follow setting, Live Activities permission and update-frequency setting. Run one manually followed game from Apple Sports, a separate News Follow Live entry and an automatically followed favorite-team game. Schedule before start and capture pregame, first live update, scoring/play change, delay/correction, final and post-final removal. Run two games concurrently and with a third unrelated activity; record source count, ordering, exact Island **presence or absence**, compact/minimal/expanded content, alert expansion, Lock Screen presentation, tap destination and whether stopping one game's alerts ends its source or only hides an alert. Repeat with Live Activities disabled for that team and with the game unavailable in the region. Do not infer an Island state from the Lock Screen card or from the older Apple TV note. [Apple Sports game guide](https://support.apple.com/en-sg/guide/apple-sports-app/apdc0cb7ad64/web), [Apple Sports team controls](https://support.apple.com/en-sg/guide/apple-sports-app/apd53158ab1f/web).

## Android integration boundary

Android permits a user who explicitly starts monitoring a background sports game to receive a Live Update, but its guidance calls for an **Unpin** action. The publisher must own the live game ID, score, clock/phase, updates, final state and Unpin result. A normal replica can observe another sports app only through the notification fields/actions it actually posts after the user grants listener access; it cannot start or stop that app's private game monitoring, or turn a generic score alert into a confirmed ongoing task. For an app-owned publisher, request promotion only when the selected build's documented requirements and user settings permit it, then inspect `FLAG_PROMOTED_ONGOING` and the native chip rather than assuming the request succeeded. Keep one game identity through score changes and distinguish each game from the notification group summary; do not duplicate the SystemUI chip or claim Apple's three-slot policy from Android notification order. [Android Live Updates](https://developer.android.com/develop/ui/views/notifications/live-update), [Android notification listener](https://developer.android.com/reference/android/service/notification/NotificationListenerService), [publisher adapter contract](../android/43-third-party-adapter-contract.md).

R10o remains `unverified` for Island presence and every parity layer until the native iPhone and selected Android runs meet the [comparison protocol](../verification/12-comparison-protocol.md). If the current iPhone shows only a Lock Screen activity, record a **negative** Island result and do not render an invented Android Island sports card for that path.
